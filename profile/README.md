# 🟢 1. Tawf Sharia

### *Halal Staking for a Trustworthy DeFi Future on Algorand*

> The first Sharia-audited staking protocol enabling Muslim investors to participate in DeFi **safely, ethically, and transparently** — powered by Algorand smart contracts and the `tawf_sharia` module.

### 🔗 Deployment

Tawf Sharia is deployed on **Algorand Testnet**, chosen for its security, scalability, and low fees:
**[https://lora.algokit.io/testnet/application/749014050](https://lora.algokit.io/testnet/application/749014050)**

### 🧩 Problem

Despite a **$3T Islamic finance market**, no protocol provides verifiable, on-chain Sharia compliance for staking — causing distrust and exclusion.

Tawf Sharia solves this via:

* On-chain Ijarah-based staking
* Verified Sharia audit proofs
* Transparent Ujrah fees and rental-based payouts
* Zero riba, zero speculation

### 💡 Highlights

* Sharia-audited staking using **Ijarah contract structure**
* Fully on-chain auditing using Algorand boxes
* Compliance-first staking layer for the Muslim world
* Modular Python + AlgoKit + React architecture

### 🎯 Target Users

* Muslim retail investors (ID, MY, UAE, TR)
* Faith-driven DeFi users
* Islamic fintech institutions

### 🛠️ Project Repos

* **Contracts:** `tawf_sharia-contracts`
* **Frontend:** `tawf_sharia-frontend`

# 🔵 2. ZK Zakat

### *Private, Verifiable Zakat with Zero-Knowledge Proofs*

> A Next.js application enabling Muslims to fulfill Zakat obligations privately and transparently through **zero-knowledge proofs**.

### 🔒 Features

* ZK-based privacy for Zakat calculations
* Campaign creation & participation
* Wallet integration (Web3)
* DAO-enabled governance
* Beautiful Shadcn UI + Tailwind
* Dark/light mode support

### 🧱 Tech Stack

* **Next.js 15**, **React 19**, **TypeScript**
* Tailwind, Radix UI, Shadcn UI
* Zod, React Hook Form
* Recharts, Date-fns
* Web3 wallet integration

### 📁 Repo Structure

Includes: campaign pages, DAO pages, dashboards, payment flow, and ZK proof configuration.

### 🚀 Quick Start

```bash
git clone https://github.com/tawf-labs/zkt-app.git
pnpm install
pnpm dev
```

# 🟣 3. QRBN DApp

### *Islamic Finance on Blockchain — Qurban, Zakat & DAO Governance*

> A decentralized Islamic finance ecosystem built using **Next.js + Lisk Sepolia**, featuring Qurban, Zakat, NFT certificates, and multi-tier Sharia-aligned governance.

### 🐐 Qurban

* Select goats or cow shares
* Transparent USDT pricing
* NFT proof of sacrifice
* Real-time progress tracking

### 💰 Zakat

* Smart nisab-aware calculator
* Zakat al-Maal & Zakat al-Fitrah
* USDT payments via smart contracts
* Impact dashboards

### 🏛️ Sharia Governance (DAO)

* Community, Organizational & Sharia Council roles
* Proposals & treasury management
* QRBN token utility

### 🔗 Smart Contracts (Lisk Sepolia)

Includes QurbnToken, QurbnGov, QurbnTreasury, QurbanNFT, ZakatNFT, etc.

### 🧱 Frontend Stack

* Next.js 14, Tailwind CSS
* Wagmi + Viem
* Xellar Wallet Kit
* React Query state mgmt
