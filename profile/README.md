# 🟢 1. Tawf Sharia([tawf.xyz](https://www.tawf.xyz/))

### *Sharia Governance and Compliance for Ethical Web3*

> A Sharia-aligned governance and compliance layer that embeds Islamic principles directly into Web3 protocols, governing how finance, treasuries, and obligations operate on-chain.

Tawf Sharia is not a single financial product. It is the **governance backbone** of the Tawf ecosystem.

### 🧩 Problem

Despite the growth of Web3, there is no native on-chain governance framework that enforces Sharia principles such as:

* Prohibition of riba, gharar, and maysir
* Ethical treasury usage
* Faith-aligned financial decision making
* Transparent religious accountability

Most halal claims today rely on off-chain promises rather than enforceable logic.

### 💡 Solution

Tawf Sharia introduces a **Sharia-first governance layer** that:

* Defines permissible financial actions
* Governs protocols, treasuries, and parameters
* Enables community-backed Sharia councils
* Makes compliance verifiable, auditable, and enforceable on-chain

### 🏛️ Core Capabilities

* Sharia-aligned DAO governance
* Multi-role governance system including:

  * Community members
  * Protocol maintainers under Tawf Labs
  * Sharia Council elected by the community
* On-chain proposals and voting
* Compliance rules enforced at the protocol level
* Governance signals consumed by other Tawf products such as ZK Zakat and QRBN

### 🔗 Supported Chains

Tawf Sharia is designed to operate across Ethereum-compatible ecosystems, including:

* Ethereum
* Base
* Lisk
* Ethiq

This ensures consistent Sharia governance across multiple networks.

### 🎯 Target Users

* Muslim Web3 builders
* Islamic fintech protocols
* DAO communities seeking ethical governance
* Sharia scholars and councils
* Faith-driven investors

### 🛠️ Role in the Ecosystem

Tawf Sharia governs:

* ZK Zakat rules and distribution policies
* QRBN treasury usage
* Protocol parameters
* Future Tawf ecosystem products

It serves as the **source of truth for Sharia compliance** across Tawf Labs.

# 🔵 2. ZK Zakat([zkt.app](https://zkt.app/))

### *Private and Verifiable Zakat with Zero-Knowledge Proofs*

> A Web3 application enabling Muslims to fulfill Zakat obligations privately and transparently through zero-knowledge proofs, governed by Tawf Sharia.

### 🔒 Features

* ZK-based privacy for Zakat calculations
* Verifiable proof of obligation fulfillment
* Campaign creation and participation
* DAO-governed parameters via Tawf Sharia
* Web3 wallet integration
* Clean and modern interface with dark and light modes

### 🧱 Tech Stack

* Next.js 15, React 19, TypeScript
* Tailwind, Radix UI, Shadcn UI
* Zod, React Hook Form
* Recharts, Date-fns
* Web3 wallet integration

# 🟣 3. QRBN DApp([qrbn.app](https://qrbn.app/))

### 🐐 Qurban
